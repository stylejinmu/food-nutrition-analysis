# 食物营养分析 Skill

[English](README.md) | 简体中文

这是一个食物与菜品营养分析 Skill，支持用户输入食物名称、菜名或上传食物图片，进行七大营养素定性分析、营养价值说明、菜谱推荐和日常摄入提醒。

## 功能

- 从图片中识别可见食物、主要食材、烹饪方式，以及可能的油、糖、盐或酱料。
- 按七大营养素进行定性分析：蛋白质、脂肪、碳水化合物、膳食纤维、维生素、矿物质和水。
- 使用“高 / 中 / 低 / 信息不足”描述营养水平，不伪造精确克数、百分比或热量。
- 说明可能的营养价值和一般健康作用，避免治疗、预防疾病或保证效果等医疗承诺。
- 在推荐菜谱前先询问用户的饮食目标，目标明确后最多推荐 3 个菜谱。
- 提供日常摄入、过敏原、特殊人群、糖盐油和食品安全注意事项。
- 不根据图片估计分量，不将图片推测当作确定配方。

## 输入方式

Skill 支持两种输入：

1. 食物名称或菜名。
2. 食物或菜品图片。

图片分析会给出识别置信度，并明确标注不确定的推测。如果无法可靠识别，会请求用户补充名称、配料或更清晰的图片。

## 输出内容

默认输出包括：

1. 图片输入时的识别结果。
2. 七大营养素概览，使用高、中、低或信息不足进行定性判断。
3. 可能的营养价值 / 健康作用。
4. 在推荐菜谱前询问饮食目标。
5. 用户说明目标后，最多推荐 3 个匹配菜谱。
6. 日常摄入、过敏、特殊人群和食品安全注意事项。

## 安全边界

本 Skill 提供一般营养信息，不构成医疗诊断、治疗或个体化饮食处方。不会宣称某种食物能够治愈、预防疾病或保证某种健康效果。涉及疾病、严重过敏、孕期特殊情况或其他特殊健康状况时，应咨询医生或注册营养师。
